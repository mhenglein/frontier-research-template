# Results

Store small, reproducible outputs here: JSON receipts, minimized witnesses,
counterexamples, checksums, and compact tables. Give each output a stable name
and link it from its `Exxx`, `Cxxx`, or `Axxx` record.

Large generated data should live outside Git with a documented retrieval path,
checksum, and version. Never treat an uncommitted local output as evidence of a
published result.
