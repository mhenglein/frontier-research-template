# Working notes

Use dated files named `YYYY-MM-DD-short-topic.md` for exploratory reasoning,
meeting notes, and longer calculations. Link useful notes from canonical
records. A note is not the current scientific state until its conclusion is
integrated into the relevant `A`, `C`, `E`, or `Q` record and, when appropriate,
`STATE.md`.

Keep scratch files, credentials, private data, and extracted document images out
of Git.
