# Reviews

Keep independent reviews here when they are longer than an issue comment. Name
the reviewed commit and records, then separate:

- mathematical review of definitions, quantifiers, hypotheses, and implications;
- software or experiment review of commands, fixtures, limits, and outputs;
- formal review of declarations, imports, runtime definitions, and axioms.

State what was checked, what was not checked, and the remaining obligations.
Agreement between agents is not independent validation when they inherited the
same argument without a separate check.
